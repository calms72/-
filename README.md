# 灵巧手实验代码（Seeed N6 版）

这套实验用六自由度灵巧手讲嵌入式视觉与控制。以人手跟随为例，摄像头拍到手指弯曲后，STM32N657 视觉板负责识别人手的 21 个关键点，MP257F 上的 PLC 程序负责把坐标换算成六路关节目标，再通过 CAN 总线驱动灵巧手。

仓库收录 **3 个视觉工程、4 个量化模型和 2 个 CODESYS 工程**。物体检测、人体姿态和手部关键点识别各有一个视觉工程。手部识别分为“找到手掌”和“估计关键点”两步，因此单独用了两个模型。全部工程都在 [软件demo/实验前](软件demo/实验前/)。

## 怎样把视觉和控制连起来

实验四和实验七处理的是同一组数据。**实验四看视觉板能否算出坐标，实验七看 PLC 能否用这些坐标驱动手指。** 做整机跟随时，可以分三步观察。

1. **看视觉板的输出。** 在实验四的 LCD 上确认 21 个关键点随人手移动。
2. **看 PLC 收到的数据。** 指导书七约定通过 RS485 发送 21 个点的三维坐标。当前仓库收录了实验四的基础视觉工程，指导书引用的 N657 关键点发送版未收录。联调时可使用配套发送固件，或在实验四工程中按协议实现发送。在 PLC 端观察 `g485RXed` 和 `CAL_START`，确认收到完整的一帧。
3. **看角度怎样变成动作。** 缓慢弯曲一根手指，依次观察 PLC 算出的角度、滤波后的目标和 CAN 指令，再与灵巧手的实际动作对照。

## 在本地打开工程

浏览源码可以直接使用上表链接。准备编译或跟做指导书时，先解压企业提供的 Seeed N6 实验资料包。在 Windows PowerShell 中执行以下命令，将 `-Source` 换成同时包含 `软件demo` 和 `指导书` 的目录。

```powershell
git clone https://github.com/calms72/elf.git
cd elf
.\restore-vendor.ps1 -Source 'D:\课程资料\实验资料包(seeed_N6版)'
```

还原脚本从原包复制七份指导书、视觉工程的库和固件依赖，以及 PLC 的设备描述和 CAN 库。视觉工程用 STM32CubeIDE 导入各自的 `STM32CubeIDE/.project`，PLC 工程用 CODESYS 打开 `.project`。模型转换、烧录地址和联调变量见[实验操作说明](实验操作说明.md)。

各组件的使用条件见对应工程的 `Package_license.md` 和组件自带的许可文件。
