# 机器人组实现

这里收录机器人组围绕 ELF 六自由度灵巧手完成的四项实验。各实验的 README 提供环境、入口命令和预期输出。只想看装置做过什么，可以直接打开下方的工作记录和实验报告。

## 代码与复现范围

| 实验入口 | 可以复现什么 | 验证结果 |
|---|---|---|
| [六轴接入与 PC 摄像头跟随](01_底层接入与控制/README.md) | 从关节名和目标位置生成 CAN 帧，预览 YAML 姿态；PC 路线从摄像头或图片提取手部关键点，映射到六轴。| 基础环境 9 项测试通过；含视觉依赖时全套 26 项通过。一张实图识别出 1 只手、21 个关键点，并输出六轴目标值。 |
| [视觉模块与板端独立随动](02_视觉跟随/README.md) | 用示例帧重放视觉模块的坐标数据，检查手指特征、候选映射、板端调度与保护逻辑。| 39 项 Python 测试和 12 个 C 测试程序通过。历史实机记录覆盖坐标接收和食指小步动作；断开电脑后由视觉驱动六轴连续随动仍待验收。 |
| [网页快速调试平台](03_快速调试平台/README.md) | 浏览器调单指和六轴姿态，录制、保存、回放动作序列；无硬件可从模拟模式开始。| Windows 上 77 项 Python 测试通过，2 项 Linux 专用测试跳过。Node.js 前端回归和本机 HTTP 模拟操作均通过。 |
| [空纸盒抓取与姿态演示](04_抓取实验/README.md) | 预览空纸盒的准备和抓取姿态，离线生成石剪布、单指、圆柱和方形位姿轨迹。| 6 项模拟测试通过，4 种轨迹逐帧核对通过。历史两轮带盒动作均到达目标附近，现场确认抓取成功；悬空提起和夹持力未测。 |

PC 摄像头版的识别、映射和控制代码放在第一个实验中，第二个实验对应黄色视觉模块与控制板的独立随动路线。PC 版使用的 MediaPipe 手部模型由项目脚本从官方来源获取并校验 SHA-256，仓库只存放获取脚本。
